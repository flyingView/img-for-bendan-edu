# 使用示例

以下是可直接交给智能体的请求示例，论文路径和内容替换成自己的材料。

## 指定方法总览图

```text
使用 $img-for-bendan-edu，阅读 paper/main.tex 和关联方法章节。
我要一张总体架构图，放在方法章节开头。
核心信息是输入如何经过三个模块形成输出，模块名称沿用论文。
保留20篇参考学习、5轮返工、6版生成图和最终软件重绘过程。
最终给我可编辑源文件、PDF和PNG，以及图注。
```

预期入口：指定单图。智能体先核对三个模块与论文证据，建立一个 `imgN/`；不会自行扩展为整篇论文的所有配图。

## 自动寻找配图位置

```text
使用 $img-for-bendan-edu，通读 manuscript.docx。
请判断论证中哪些关系用图表达更清楚，完成最有价值的配图。
在可编辑稿件中插入图片、图注和对应引用，并保留可回退的原稿。
配图要简洁明确，图例清晰，色调协调。
```

预期入口：论文配图。先生成 `论文配图总规划.md`，逐张执行，记录最终插入位置和正文检查结果。

## 定量结果图

```text
使用 $img-for-bendan-edu，为实验章节设计主结果图。
真实数据位于 results.csv，误差定义在实验设置中。
按完整流程学习参考与迭代布局，最终用数据绘图代码重绘。
输出每个面板对应的实际数据列、图例和绘图脚本。
```

预期行为：图表数据层从源数据生成；生图用于版式、配色或概念面板探索。最终数值、误差和坐标回到真实数据计算。

## 继续上次任务

```text
继续 重型绘图任务/img2。
读取已有状态、需求、参考学习和最新返工，从实际断点继续。
```

预期行为：检查已有版本和记录，不新建 `img3/`，不覆盖已经完成的阶段。

## 终稿局部修订

```text
修改 img1 的最终图：统一两个模块的标签，将图例移到右上角，主线颜色改得更柔和。
保持数据、结构和其他内容，保存新的终稿与源文件版本。
```

预期行为：直接编辑软件重绘源文件，检查局部变化并保存修订版；不重复全套文献检索。
